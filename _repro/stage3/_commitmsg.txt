feat(stage3): teacher-student temporal alignment [OURS] + soft gate + pure pursuit

The paper specifies alignment in ONE sentence ("for each state s in the
buffer D, the teacher policy pi_Teacher provides the recommended action
a_teacher for that state") plus Fig.3. Everything below is [OURS].

teacher.py
- AlignConfig.align in {index, nn, mono, window} (default window=8):
  monotone + rate-limited, insensitive to waypoint density, and blind to
  the far branch at self-intersections. `monotone` retained as the
  align="" fallback => fully backward compatible.
- soft gate w = exp(-d^2 / 2 sigma^2) (default). Fixes a SILENT failure:
  reward = is_lift*2 + is_grasped*2 with is_lift always true => almost
  purely sparse reward => a random student never enters the eps ball =>
  hard mask all-False => L_KL == 0 => only RL trains, forever, while the
  loss curve still falls and nothing errors. Also avoids inf/nan in
  Eq.(9) lambda = 10^(log10 L_RL - log10 L_KL).
- lookahead_dist = 0.05 m (pure pursuit along arclength). Fixes another
  silent no-op: RRT* spacing is ~6 mm, so the old integer lookahead=1
  asked for a 0.06 action -- the teacher "existed but said nothing".
  Now 0.540. lookahead_dist=0 restores the old semantic exactly.
- gripper_src in {j, tgt, none}: the closing instant is a CONTACT EVENT,
  not a coordinate. Binding it to j (the nearest-waypoint time) imports a
  desync the author's open-loop follow_path never had.
- reanchor_on_reset: j0 = nearest_index(state) on env reset.
- arclen table rebuilt in set_trajectory(); new nearest_index().

ppo_kl.py
- New flags: --align --align-window --lookahead-dist --gate --gate-sigma
  --gripper-src --align-dist-dims --reanchor-on-reset. Defaults are the
  recommended combination, so a plain run picks them up.
- mask dtype bool -> float (0,1]; all bool(mask.any()) -> sum() > 1e-12.
- New metrics w (=mean soft weight), hit, d, j in CSV and the log line.
- BUGFIX: teacher.reset(mask=done) used to live inside
  `if args.teacher in ("joint","standin")`, so under --teacher traj the
  teacher never rewound after an env reset and stayed pinned to the end
  of the trajectory. Reset is now unconditional.
- BUGFIX: stand-in re-anchoring assigned teacher.tau in place, which
  never rebuilt the arclength table; now goes through set_trajectory().
- Drop the computed-but-never-used `bcov`.

Verified: 8 regression assertions in teacher.py all pass (pure pursuit
0.540 vs 0.06 old; window j=[0,3,6,9,...]; soft gate 1.0 / 3.05e-06,
never exactly 0; gripper_src='none' emits exact 0; backward excursion
does not rewind; reanchor j=50). End-to-end smoke on Windows CPU, 1 env,
200 steps: exit 0, L_RL ~0.49 -> L_KL ~21.6 -> lambda ~0.0229.
